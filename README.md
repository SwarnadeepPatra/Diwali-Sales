# 📊 Diwali Sales Analysis

Exploratory Data Analysis (EDA) of the **Diwali Sales Dataset** using Python to uncover customer purchasing behavior and sales trends.

## 📌 Project Overview

This project analyzes Diwali sales data to identify patterns based on customer demographics, occupations, states, and product categories. The insights can help businesses understand customer preferences and improve marketing strategies.

## 🛠 Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

- Data Cleaning & Preprocessing
- Handling Missing Values
- Exploratory Data Analysis (EDA)
- Customer Demographic Analysis
- State-wise Sales Analysis
- Occupation-wise Sales Analysis
- Gender & Age Group Analysis
- Product Category Analysis
- Data Visualization

## 🎯 Key Insights

- Married women aged **26–35 years** contributed the highest sales.
- Customers from **Uttar Pradesh, Maharashtra, and Karnataka** generated the highest revenue.
- IT, Healthcare, and Aviation professionals were among the top spending customer groups.
- Food, Clothing, and Electronics were the most popular product categories.
